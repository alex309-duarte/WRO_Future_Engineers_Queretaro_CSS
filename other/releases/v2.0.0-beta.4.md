## v2.0.0-beta.4 — Board firmware (pre-release)

**Date:** 2026-11-09

Fourth beta of the design v7 documentation for the **WRO 2026 Future Engineers International Final** (Puerto Rico, December 2026). Its main addition is the firmware of the Hiwonder ROS Robot Controller, so the repository now holds the code of every programmed component on the robot.

### Highlights
- **Our board firmware `pos-v8`** in `firmware/hiwonder_pos-v8/`: the image running on the robot (`.hex` / `.bin` with SHA-256), our patch over Hiwonder's firmware (`extended_m1.patch`, 12 files: position control and HOLD on the drive motor, IWDG watchdog, smaller fixes), the GCC build scripts, the `MOTOR_EXT` protocol description, the version history `pos-v4` to `pos-v8`, and the flashing and build steps.
- **Hiwonder's original firmware** in `firmware/hiwonder_original/`: Hiwonder's official source project (V1.2) and factory recovery images, unmodified and credited to Hiwonder, with the third-party libraries it uses and their licenses.
- **New Figure 10:** architecture of the extended firmware (`schemes/firmware/`). Later figures renumbered.
- **IMU corrected to QMI8658** (the chip the board firmware drives) in the README, the journal and the v7 wiring diagram.
- **Emergency-stop wording:** the board firmware has no command timeout; the IWDG watchdog only resets a hung firmware.
- **Engineering Journal:** firmware section and figure, logbook entries for the firmware milestones and the switch to a single 3S pack, reproducibility table.
- **Videos:** links to the national official rounds and the team's YouTube channel (README §11).
- **License note:** the MIT License covers the team's work; third-party code keeps its authors' terms.
- **Release dates** corrected in the README, the journal and the beta release notes.
