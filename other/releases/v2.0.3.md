## v2.0.3 — International Final version (design v7)

**Date:** 2026-11-21

**Current version** of the documentation and code of ***"The Maker"***, design v7, for the **WRO 2026 Future Engineers International Final** (Puerto Rico, December 2026). Design v6, the vehicle of the Mexico National Final (2nd place), stays available as release `v1.0.0`.

### Changes since v2.0.2
- **Obstacle Challenge code updated.** The gyro correction at every corner now uses the median tilt of all the walls in view, measured once the robot is still, instead of one wall. After the start button the robot waits up to 2 s for one side to open before it chooses the driving direction. The distances to the front wall were re-tuned for the new position of the LiDAR. Every run writes a heading log (CSV) with the yaw and the angle of each wall at every LiDAR scan.
- **One LiDAR mounting value for both programs:** `Lidar_Angle_Orientation_fixed_to_robot` in `common_var.h`.
- **README brought up to the code:** thresholds, corner diagram, parking table and parking figures, edge cases and the heading section (§6.2, §6.3, §6.6, §6.8). §6.9 states that the run logs of 2026-11-08 were measured with the earlier settings and records what the tests after that date changed.
- **Print files updated to the current CAD:** 13 STL files, 15 pieces. A one-piece Ackermann arm replaces three parts; the chassis base, the LiDAR support, the servo arm, the steering link and the standoff were re-exported. The preview of the printed parts is drawn at one scale.
- **CAD:** new SolidWorks assembly (`models/cad/v7_assembly/Assem1.SLDASM`); README §4.1 shows seven views of it and one full turn.
- **Surprise rule:** first frames with real modified signs and the box ratios measured in them (README §6.10). The ratio check is still in development.
- **Assembly instructions easier to find:** a large link above the overview of the 37 steps.
- **ST-LINK V2 programmer** added to the bill of materials and to the firmware and setup instructions, with a picture and a purchase link.
- **Engineering Journal:** updated to the code and print files of this release, with the tests of 2026-11-16 and their results (Sections 4.4, 4.7, 4.11 and 6.5).
