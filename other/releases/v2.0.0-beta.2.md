## v2.0.0-beta.2 — Review fixes (pre-release)

**Date:** 2026-11-10

Second beta of the design v7 documentation for the **WRO 2026 Future Engineers International Final** (Puerto Rico, December 2026), after a full review of the repository against the code and the WRO 2026 rules.

### Highlights
- **Final parking described as implemented:** the robot finds the parking lot by counting sections and parks on LiDAR distances and gyro angles; the model's `xparking` class only keeps the magenta markers from being taken for pillars. New "Final parallel parking" subsection and `FinalParking` state.
- **Program messages in English:** all user-facing output, error and test messages of the v7 programs translated (logic unchanged; offline tests 53 + 31 checks, 0 failures).
- **Design v7 figures:** v7 Ackermann linkage at full lock (45.9°) and a new v7 software data-flow diagram; v6 figures labelled as design v6; all figures renumbered.
- **Rule compliance list** (wireless, single switch and start button, automatic calibration) with rule numbers.
- **Reproducibility:** RPLidar SDK build step, corrected build flags and file paths, board firmware note (`pos-v8`, position-control command).
- **Consistency fixes:** test counts, design numbers, iteration table, LiDAR-height history, steering limits, cross-references and anchors; calibration steps no longer depend on tools outside the repository.
- Engineering Journal updated accordingly.
