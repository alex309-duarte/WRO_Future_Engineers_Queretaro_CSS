## v2.0.4 — International Final version (design v7)

**Date:** 2026-11-22

**Current version** of the documentation and code of ***"The Maker"***, design v7, for the **WRO 2026 Future Engineers International Final** (Puerto Rico, December 2026). Design v6, the vehicle of the Mexico National Final (2nd place), stays available as release `v1.0.0`.

### Changes since v2.0.3
- **Interactive 3D model of the vehicle.** The SolidWorks assembly opens in the browser with its colours: rotate, zoom, standard views, an exploded view that takes the vehicle apart, and the name of every part. It is at the top of README §4.1, with an animation of the exploded view that opens it; the page, the model and the tools to rebuild it are in `models/cad/viewer/`. Address: https://sebassesq.github.io/the-maker-3d/
- **The whole vehicle in one STL** (`models/cad/vehicle_v7.stl`), which GitHub shows in its own 3D viewer.
- **SolidWorks assembly of the current design:** `models/cad/v7_assembly/Assem1.SLDASM` and its parts (50 files). It was announced in v2.0.3 but was missing from that tag; it is in the repository from this release on.
- **Development repository of the board firmware linked:** https://github.com/JRavenelco/hiwonder-brick holds Hiwonder's project and our extension, the host library, the bench tools and the dated bench logs. It is linked from the top of the README, from the firmware section (§6.1) and from the firmware page.
- **Explainer video of the board firmware** (9:52): the firmware built from scratch in STM32CubeIDE, how it works, and flashing and testing it. In README §6.1 it sits next to the firmware development repository; it is also in §11, on the firmware page and in `video/video.md`.
- **Decision cards renumbered D1 to D9 in the order they appear,** with an index table at the top of the README (card, decision, section).
- **README:** the interactive 3D model now comes before the CAD views, in a highlighted box; three more blocks of supporting detail are folded (the nine changes of the v7 mission, the parking sequence step by step, the text of the surprise rule). Nothing was removed.
- **Clickable pictures are marked.** Video previews carry a play button; previews that open a page, a document or a product page carry a round blue pointer mark, explained in the reading guide at the top. The pictures of the coaches appear once, above their biographies.
- **Engineering Journal:** release table, logbook and repository contents updated.

**Changes since v2.0.3:** https://github.com/alex309-duarte/WRO_Future_Engineers_Queretaro_CSS/compare/v2.0.3...v2.0.4
