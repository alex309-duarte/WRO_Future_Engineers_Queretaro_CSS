## v2.0.0-alpha.3 — Commented source code (pre-release)

**Date:** 2026-11-09

Third development snapshot of design v7, the vehicle for the **WRO 2026 Future Engineers International Final** (Puerto Rico, December 2026). Documentation in progress; not the final submission.

### Highlights
- **Source code commented in English.** Both v7 programs are now commented in English: the Open Challenge (`src/ondevice/`, including the Hiwonder board layer, the SPIKE compatibility layer and the offline tests) and the Obstacle Challenge (`src/cpp/object_detection_hiwonder_h10/`). Each file has a header saying what it does, which hardware it talks to and which challenge uses it. Functions have doc comments with units, and calibration constants say what they mean. The program logic is the same as in `v2.0.0-alpha.2`: apart from the steering test and two error messages (below), only comments changed.
- **Steering limit documented as ±35°** from centre (`kDireccionMaxGrados`: 145 servo units each side, positions 605–895) in the code, the README (§4.2, decision card D3) and the Engineering Journal. The offline steering test now checks ±35° (`make test`: 53 checks, 0 failures). Two error messages now name the steering servo correctly (HX-35H).
