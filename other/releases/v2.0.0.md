## v2.0.0 — International Final version (design v7)

**Date:** 2026-11-10

Documentation and code of ***"The Maker"***, design v7, for the **WRO 2026 Future Engineers International Final** (Puerto Rico, December 2026). Design v6, the vehicle of the Mexico National Final (2nd place), stays available as release `v1.0.0`.

### What is in this release
- **Vehicle:** Hiwonder ROS Robot Controller with our firmware `pos-v8`, JGB37-520 drive motor, HX-35H steering servo, RPLidar S2L, Camera Module 3 Wide with a Hailo-8, 3S NCR18650B pack, Raspberry Pi 5.
- **Code:** Open Challenge and Obstacle Challenge programs in C/C++, commented in English, with 53 + 31 offline tests; board firmware as a patch over Hiwonder's source, with the built image and build scripts.
- **Documentation:** README organised by the five rubric criteria, Engineering Journal (international edition), wiring diagram, test log, release notes of every version.

### Changes since v2.0.0-beta.4
- **Print files of design v7:** 12 STL files (16 pieces) in `models/cad/Stl/v7/`, with a parts table, quantities, printer and material, and the Creality Print presets.
- **Assembly instructions:** rewritten in English as 31 steps in build order, and linked from a new block in README §10.
- **Build from a fresh clone fixed:** the Slamtec SDK is now a declared Git submodule (`git clone --recurse-submodules`).
- **New README sections:** connection table (§5.1), what each test changed (§6.9.3), failure log (§7.5), known limitations and next steps (§7.6), competition-day checklist (§9.9).
- **Obstacle layouts A to E** of the test runs drawn on the playfield (README Figure 16, `other/testing/`).
- **Videos:** the official rounds of the National Final are on YouTube.
- **`src/` pages** describe design v7; the design v6 program has its own README.
- **Corrections:** journal budget (v7 Bill of Materials), start-up current percentage, speed comparison at matching battery voltage, BMS name; design v6 diagrams moved into a collapsible section.
- **Clean-up:** documents translated to English, duplicate photos and editor settings removed.
